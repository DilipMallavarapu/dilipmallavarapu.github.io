Research Interests

My research centers on finding and root-causing memory- and logic-level vulnerabilities in real deployed systems, then generalizing what I find into reusable methodology. Four areas I want to keep pushing on in a PhD:

01 Web Application Security
Source-code-review-driven vulnerability discovery in production web platforms, including injection, mass assignment, race conditions (TOCTOU), and authorization logic flaws. My FOSSBilling CVEs (RCE via config injection, promo-code race condition, mass assignment) are case studies in this space.
02 IoT & Embedded Firmware Security
Static binary analysis of ARM ELF firmware images to recover authentication logic, hidden endpoints, and no-auth code paths in physical access control and network devices, reversing compiled logic back into an exploitable model of the system.
03 Mobile & Payment SDK Security
Security analysis of mobile SDKs and payment integration libraries, examining how trust boundaries between client, SDK, and backend are (mis)enforced, motivated by disclosures to payment and financial infrastructure providers.
04 LLM & AI System Security
Adversarial robustness of LLM-integrated systems, including prompt injection, indirect injection via tool/RAG outputs, jailbreak techniques, and empirical evaluation of guardrails, an active area from my graduate coursework at UAB that I want to take into a PhD.
