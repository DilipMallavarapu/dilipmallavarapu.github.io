Arbitrary PHP Code Injection via Unescaped Config Serialization → Remote Code Execution
FOSSBilling serializes config values into a PHP file using string interpolation with no escaping. A single quote in any string value breaks out of the PHP string literal, injecting arbitrary code that executes on every subsequent HTTP request as www-data.

Mass Assignment of group_id in Guest Registration Allows Unauthorized Promo Code Use
The public registration endpoint passes the full request body into the internal client creation method without stripping admin-only fields. An unauthenticated attacker can supply a group_id to assign themselves to any client group and access group-restricted promo codes.

Race Condition in Cart Checkout Bypasses Promo Code Usage Limits
FOSSBilling's promo usage check and increment are non-atomic — three separate operations with no database locking. Concurrent checkout requests all read the same stale counter, all pass, and all create discounted orders. A single-use code can be exploited unlimited times.
